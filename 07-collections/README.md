# Library Collection Manager

A simple console application written in C#. This is my educational project to practice and learn basic Object-Oriented Programming (OOP) concepts.

## Features

* **Book creation:** Defines a custom `Book` class to store information about books.
* **Data assignment:** Keeps track of the book's title, author, and number of pages.
* **Collection management:** Uses a dynamic `List<Book>` to store multiple book objects in one place.
* **Automated output:** Uses a `foreach` loop to iterate through the entire collection and print specific details (Title and Pages) to the console.

## What I learned in this project

* How to define a `class` and set default empty strings to avoid null reference warnings.
* How to create multiple independent objects (`Book1`, `Book2`, `Book3`) from a single class.
* How to initialize and populate a `List<T>` with custom objects.
* How to use a `foreach` loop to extract and display data from a collection efficiently.
