# Student Information

A C# console application to collect and analyze student grades.

## Features
* **Collect Grades:** Asks the user to enter 5 grades one by one.
* **Error Checking:** Checks if the grade is strictly between 1 and 5. If not, it asks to try again.
* **Auto Calculations:** Instantly finds the maximum, minimum, and average score.

## What I learned in this project
* How to use `List<int>` to store multiple numbers.
* How to use LINQ (`.Max()`, `.Min()`, `.Average()`) for quick math (Declarative Programming).
* How to use `for` loops to repeat actions a set number of times.
* How to use `while (true)` and `break` to protect the program from wrong user input.
